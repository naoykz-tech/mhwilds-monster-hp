# 学習中の質問と答え

## REFramework・ゲームの調べ方

**Q. TDB Methods とは？**
TDB は Type DataBase（型のデータベース）。ゲームの中にどんなクラスがあり、何ができるかの名簿。TDB Methods はそのクラスにできること（メソッド）の一覧、TDB Fields は持っているデータ（フィールド）の一覧。

**Q. app.cPlayerManageInfo が大量に出てくるが、何を探せばいい？**
app.cPlayerManageInfo はメソッドの名前ではなく、メソッドが返すものの種類（ハンター1人分の情報）。その行のメソッド名の部分を見て、カッコの中が空のものを探す。

**Q. カッコの中に System.Guid や System.Int32 があるメソッドは？**
「どの人か」を指定する情報（引数）が必要なメソッド。番号（Int32）や ID（Guid）を渡す必要があるので、自分のプレイヤーを取るときは対象外。

**Q. 調べている間にモンスターに襲われる**
ベースキャンプや拠点など、モンスターが来ない安全な場所で調べる。

**Q. Steam を経由せずにゲームフォルダを開くには？**
エクスプローラーのアドレスバーにパスを入力するか、autorun フォルダをクイックアクセスにピン留めする。

## Lua の書き方

**Q. local とは？**
「自分のパソコン」という意味ではなく、新しく箱（変数）を作るときに付ける言葉。その箱はこのあたりのコードの中だけで使う、という宣言。

**Q. pm とは？**
app.PlayerManager を入れておく箱に、自分で付けた名前。PlayerManager の頭文字。

**Q. sdk とは？**
ソフトウェア開発キットの略。REFramework が用意している、ゲームの中身を触るための道具箱。

**Q. get_managed_singleton とは？**
Object Explorer の Singletons 一覧から、名前で1つ取ってくる道具。シングルトンは「ゲームの中に1つしかない係」のこと。

**Q. nil とは？ null と違う？**
どちらも「空っぽ」という意味。JavaScript などでは null、Lua では nil と書く。

**Q. = と == の違いは？**
= は「右のものを左の箱に入れる」、== は「同じかどうか比べる」。ほとんどのプログラミング言語で共通のルール。

**Q. ~= とは？**
「等しくない」という意味（Lua の書き方）。JavaScript や Python では != と書く。

**Q. なぜ "getMasterPlayer" をダブルクォーテーションで囲む？**
囲むと「ただの文字」になる。call にはメソッド名を文字として渡すルール。囲まないと、その名前の箱を探してエラーになる。

**Q. if の文は改行しないといけない？**
改行しなくても動く。ただし読みやすいように改行して書くのがおすすめ。

**Q. なぜモンスターの前にプレイヤーの情報を取るの？**
プレイヤーは画面にいつもいて確認しやすいから。それに、「係を呼んでメソッドで情報を取り出す」流れはモンスターでも同じなので、その練習になる。

## つまずいたこと

**Q. Player OK が Reset Scripts の瞬間だけ出て消える**
コードが re.on_frame の end) より外に書かれていた。外に書くと読み込み時に1回しか動かない。end) をいちばん最後に移動して解決。

**Q. 英語キーボードで Shift + ハイフンを押すと = が出る**
Windows がキーボードを日本語配列だと認識していたため。キーボードの設定を英語配列に変えて解決。
